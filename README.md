# AI-Generated Image Detection

## Project Overview
AI-Generated Image Detection is a machine learning project designed to classify images as either AI-generated or real. The project uses deep learning and image processing techniques to analyze images and predict their class.

## Objectives
- Detect AI-generated images and distinguish them from real images.
- Preprocess images for model prediction.
- Train and evaluate a deep learning classification model.
- Provide predictions for previously unseen images.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pillow
- Matplotlib

## Dataset
The dataset contains images belonging to two classes:
- **Real:** Images captured or created through conventional photography or imaging.
- **AI-generated:** Images produced using generative AI tools.

Dataset source: 

For large datasets, download the data separately instead of uploading all images to this GitHub repository.

## Model
The project uses a deep learning image classification model implemented using TensorFlow/Keras.

The trained model can be saved in HDF5 format (`.h5`) and loaded for inference.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sreeja2110/MLProject.git
   cd MLProject
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Download the dataset and trained model if they are stored externally.

## Limitations
- Prediction accuracy depends on the training dataset and model quality.
- Performance may vary on images generated by unfamiliar AI tools.
- Predictions should not be treated as definitive proof of an image's origin.
